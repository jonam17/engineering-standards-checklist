# Evidence register

Use this register to link findings and controls to evidence that can be reviewed and reproduced. Avoid storing secrets, personal data, production credentials, or unnecessary sensitive records in the repository.

| Evidence ID | Related control / finding | Evidence type | Source / location | Collection date | Collector | Integrity / version | What it demonstrates | Limitations |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

Evidence examples: source/configuration references, architecture or data-flow diagrams, test and CI results, scan output, accessibility reviews, performance measurements, deployment/recovery records, approved policies, and direct observations.
